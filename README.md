Exploratory Data Analysis (EDA)

Project Overview

This project focuses on performing Exploratory Data Analysis (EDA) on a customer dataset using Python, Pandas, Matplotlib, and Seaborn.

Objectives

* Understand the structure and characteristics of the dataset
* Perform statistical analysis
* Identify patterns and trends
* Create meaningful data visualizations
* Extract useful insights from the data

Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Google Colab
* GitHub

EDA Tasks

* Dataset overview
* Descriptive statistics
* Missing value analysis
* Distribution analysis
* Categorical data analysis
* Correlation analysis
* Data visualization
* Business insights

Dataset

The dataset contains customer information such as age, gender, city, income, purchase amount, purchase date, and category.
